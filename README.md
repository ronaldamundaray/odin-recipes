# Odin Recipes

This is a simple website with a main index page containing links to various recipes.

### Skills Demonstrated
In this project, I demonstrate my knowledge of:
* Basic HTML structure and boilerplate.
* Essential HTML elements (headings, paragraphs, lists, links, and images).
* Working with element attributes.
* Git version control (commits, pushing to GitHub).

### What I Learned
Through this project, I learned:
* How to structure a basic HTML document.
* How to use semantic HTML elements such as heading, lists, and links.
* How to create relative links between pages.
* How to add images using the <img> element and its src, alt, width and height attributes.
* How to organize files and directories for a simple website.
* How to use Git to track changes and create meaningful commits using the Conventional Commits specification.
* How to push a local Git repository to GitHub.
